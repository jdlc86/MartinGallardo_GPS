# Modern UI · Changelog

## v1 — 2026-08-31

### GPS Pro
- Rediseño mobile-first.
- Medidor visual de precisión.
- Clasificación humana de calidad GPS.
- Conservación automática de la mejor lectura.
- Haptic feedback al mejorar señal y confirmar/error.
- Telegram MainButton para confirmar ubicación.
- Telegram SecondaryButton para mejorar precisión.
- Respeto de safe areas y tema claro/oscuro.
- Mantiene cierre automático 2 s después de guardar.

### Expediente 360º
- Cabecera con matrícula y estado.
- Resumen temporal.
- Ubicación actual vs histórica claramente diferenciada.
- Navegación solo cuando el vehículo sigue aparcado.
- Google Maps mediante Telegram `openLink()` para no cerrar la Mini App.
- Galería agrupada por fecha y etapa.
- Ampliación de fotos dentro de la Mini App.
- OCR y overrides en tarjetas legibles.
- Historial como timeline vertical.
- BackButton nativo para volver a búsqueda.
- Haptic feedback en acciones relevantes.

### Compatibilidad
No se han cambiado las reglas de negocio, estados de vehículo, permisos ni auditoría.
